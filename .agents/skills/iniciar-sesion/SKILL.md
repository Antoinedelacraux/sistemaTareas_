# Workflow: iniciar sesión
1. Leer `AGENTS.md` y `docs/PROJECT_CONTEXT.md`, `docs/REQUIREMENTS.md`, `docs/DECISIONS.md`, `docs/ROADMAP.md`, `docs/PROGRESS.md`, `docs/SESSION_HANDOFF.md`.
2. Revisar `git status --short`, rama actual y `git log -3 --oneline` si existe Git.
3. Inspeccionar archivos relevantes; no asumir que la documentación refleja la implementación si no se verifica.
4. Resumir estado verificado, diferencias, decisiones abiertas, riesgos, último commit real y siguiente tarea recomendada.
5. No codificar, modificar archivos, instalar ni hacer commits durante este diagnóstico, a menos que el usuario lo haya pedido.
