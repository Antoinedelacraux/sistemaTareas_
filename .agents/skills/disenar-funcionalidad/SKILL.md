# Workflow: diseñar funcionalidad
1. Seleccionar RF/RN y casos de uso autorizados.
2. Describir flujo normal, alternos, errores, permisos, reglas y estados UI.
3. Diseñar contratos de datos/API, validaciones, persistencia y pruebas para la historia sin sobreconstruir.
4. Detectar divergencias con otros módulos y registrar ADR si hay elección técnica.
5. Entregar diseño verificable al Orquestador y actualizar solo documentos aplicables.
