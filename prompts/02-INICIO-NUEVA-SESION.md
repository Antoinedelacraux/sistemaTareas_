# Prompt de nueva sesión

Actúa como Orquestador del proyecto Seguimiento de Tareas del área de Planeamiento. Ejecuta el skill `/iniciar-sesion` o sigue su procedimiento completo. Reconstruye el estado desde archivos versionados y Git, no desde suposiciones del chat. Indica qué requisitos están cerrados, qué trabajo existe realmente, cuáles son los riesgos, cuál fue el último commit y cuál debería ser el siguiente incremento. No modifiques archivos todavía.
